El PRESTADOR se compromete a disenar, desarrollar, configurar, optimizar y poner en produccion el portal web oficial, portfolio institucional y plataforma de comercializacion Fine Art Giclee internacional para la obra artistica del CLIENTE, conforme a los estandares de ingenieria web ultraligera (Astro SSG, rendimiento 100/100, arquitectura Zero-JS y diseno minimalista de galeria).

### SEGUNDA. ADQUISICION DE DOMINIO Y GESTION DE HOSTING
1. **Dominio Oficial:** El PRESTADOR adquiere, registra y gestiona por cuenta del CLIENTE el nombre de dominio exclusivo: **`ivanmoratillo.com`**.
2. **Titularidad:** Queda expresamente convenido que la titularidad moral y los derechos sobre la marca personal del dominio pertenecen de forma exclusiva al CLIENTE. En caso de extincion del servicio de mantenimiento, el dominio sera transferido a requerimiento del CLIENTE sin penalizacion alguna.
3. **Servidor y Alojamiento (Hosting):** El PRESTADOR proveera e integrara el servidor de alto rendimiento con aceleracion LiteSpeed ubicado en centros de datos europeos, optimizado para trafico internacional ilimitado y entrega inmediata de imagenes de alta resolucion.
4. **Seguridad Perimetral (Cloudflare):** El servicio incluye la configuracion del escudo perimetral Cloudflare (CDN global, certificado de seguridad SSL encriptado de nivel bancario y proteccion contra ataques de denegacion de servicio Anti-DDoS).
