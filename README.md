# Ivan Moratillo – Arquitectura & Arte (Web Nivel 5 Agent-Native)

Sitio web oficial, galeria de autor y plataforma de venta de obras originales y giclee prints para el arquitecto y artista plastico Ivan Moratillo (Lima / Berlin).

Desarrollado bajo la metodologia Spec-Driven Development (SDD) del Laboratorio KusiAI con Astro SSG y optimizacion GEO (Generative Engine Optimization).

## Estructura del Proyecto
- `.specify/`: Especificaciones (`specify.md`), arquitectura tecnica (`plan.md`) y lista de tareas (`tasks.md`).
- `public/obras/`: Archivo fotografico de las obras y dibujos del autor.
- `public/llms.txt`: Protocolo de recuperacion de contexto para agentes de IA (ChatGPT, Claude, Perplexity).
